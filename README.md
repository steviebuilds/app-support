# Ducky support

Ducky is the arcade game where you run, jump, fly and survive. This repository contains public support and privacy information; it does not contain the app's source code.

## Help

Tap anywhere during a run to jump. Landing restores your two jumps. Collect coins to buy hats and power-ups. Pause using the red control in the top-right corner.

Version 2.0 runs without ads. New Remove Ads purchases are disabled in this version. Restore Purchases remains available for existing ad-free purchases. Coin packs are consumable and cannot be restored; earned and purchased coins are saved on the device.

If an App Store purchase is pending, do not buy it again. Open Options and choose Retry purchases. Use Restore Purchases with the Apple Account that made an earlier ad-free purchase.

Before changing phones or removing Ducky, keep an iPhone backup. Ducky does not provide its own cloud save service.

For support, [open an issue](https://github.com/steviebuilds/app-support/issues/new) with the Ducky version, iOS version and a description of the problem. Issues are public: do not include passwords, payment details, receipts, Apple Account details or other private information.
